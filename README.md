# Финстарт (Finstart)

**Финстарт** — веб-приложение для изучения финансовой грамотности в игровом формате. Пользователи проходят короткие уроки и квизы, копят алмазы, открывают достижения и отслеживают прогресс — по аналогии с языковыми приложениями, но про бюджет, сбережения, кредиты и безопасность.

---

## Зачем создано

Проект задуман как **доступная и понятная платформа** для тех, кто хочет разобраться в личных финансах без сухих лекций и перегруженных таблиц.

Основные идеи:

- **Короткие уроки** — темы разбиты на уровни и шаги, можно учиться с телефона или десктопа.
- **Интерактив** — вопросы с обратной связью, повтор ошибочных ответов в конце урока.
- **Мотивация** — стрики, алмазы, каталог достижений и магазин наград.
- **Личный кабинет** — профиль со статистикой, настройки аккаунта, история прогресса.

Лендинг знакомит с продуктом; после регистрации пользователь попадает в обучение (`/learn`), курсы, достижения и магазин.

## Стек технологий

| Слой | Технологии |
|------|------------|
| **Frontend** | React 18, TypeScript, Vite, React Router, Tailwind CSS, Motion, Lucide |
| **Backend** | Go, Gin, GORM |
| **База данных** | PostgreSQL 15 |
| **Аутентификация** | JWT (access + refresh) |
| **Инфраструктура** | Docker Compose, golang-migrate, pgAdmin (опционально) |

Структура репозитория:

- `frontend/` — клиентское приложение (SPA)
- `backend/` — REST API и бизнес-логика
- `backend/migrations/` — SQL-миграции схемы и сидов
- `docker-compose.yml` — локальный запуск БД, миграций, API и фронта

## Быстрый старт (локально)

1. Скопируйте и настройте `backend/.env` (подключение к БД, JWT и т.д.).
2. Из корня репозитория:

```bash
docker compose up --build
```

3. Откройте фронтенд (порт зависит от профиля в `docker-compose.yml`, обычно через сервис `frontend` или `frontend-dev`).

API по умолчанию: `http://localhost:8080`  
PostgreSQL (хост): `localhost:5433`
